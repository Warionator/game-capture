game-capture 1.0.0 - portable build (Windows 10/11 x64)

RUN
  1. Extract the whole folder somewhere permanent (e.g. C:\Tools\game-capture).
     Keep the "binaries" folder next to game-capture.exe - it holds FFmpeg.
  2. Double-click game-capture.exe. Windows SmartScreen may warn because the
     build is unsigned: "More info" -> "Run anyway".
  3. WebView2 is preinstalled on Windows 10/11. If the window stays blank,
     install the Evergreen runtime from microsoft.com/edge/webview2.

WHAT THIS BUILD CHANGES ON YOUR PC (both on by default, per the spec)
  - Disables Windows Game Mode for your user
    (HKCU\Software\Microsoft\GameBar). Undo: Settings > System.
  - Registers "start with Windows" pointing at THIS exe location
    (HKCU\...\CurrentVersion\Run, value "game-capture").
    Undo: Settings > System > Start with Windows (turn off before deleting
    the folder).
  Captures go to %USERPROFILE%\Videos\game-capture (change in Settings).

SUGGESTED TEST PASS
  [ ] Settings > Video: which encoders are listed as working (NVENC/AMF/QSV)?
  [ ] Click "Capture desktop" in the top bar -> status shows encoder and
      "zero-copy"; wait 30 s; Alt+F10 saves a clip; it appears in the gallery
      and plays.
  [ ] Start a game -> it is detected (name + icon in the top bar) and the
      replay buffer starts by itself.
  [ ] In game: Alt+F10 (clip), Alt+F9 (start/stop recording), Alt+F8
      (bookmark), Alt+F12 (screenshot).
  [ ] Open the clip in VLC/MPC: audio tracks 1 Master, 2 Game, 3 Mic,
      4 Discord. Windows notification sounds should NOT be on the Game track.
  [ ] While recording, alt-tab to another app for ~5 s: the clip shows the
      "Game not in focus" screen for that part, never your desktop. The top
      bar shows "Not in focus" meanwhile. Status bar should say "Game window".
  [ ] Gallery: a single click opens the player. Drag the blue handles to trim,
      "Audio tracks" -> mute Microphone, Save... -> "Save as a copy": a
      *_edit file appears, trimmed, without mic. Try "Overwrite original" too.
  [ ] Player "Delete" button removes the clip.
  [ ] Settings > Audio > Microphone: turn on Noise gate, talk and stay quiet –
      the badge flips between "open" and "gated"; move the threshold marker.
  [ ] Settings > Replay buffer: type 4:30 in the length box -> saved clips are
      ~4.5 min long.
  [ ] Run ShareX (region capture) or OBS: they must NOT be detected as games.
  [ ] Launch a game: a popup with a chime appears in the top-left corner
      ("Capturing <game>"). It must not steal focus from the game. Save a
      clip -> "Saved last 2:00" popup with a different chime. Settings > System
      > In-game popups: change the corner, press Preview.
  [ ] Settings > Recording: turn on "Record full sessions automatically",
      start a game -> recording starts by itself; quit the game -> the
      session is saved.
  [ ] Set a different Recording quality vs. Clip quality (e.g. 1080p30 vs
      1440p60): clips and recordings come out at their own settings.
  [ ] With no game running: Record and Screenshot are disabled and the
      hotkeys do nothing, unless Settings > Recording > "Allow capture
      outside games" is on.
  [ ] Settings > Audio with nothing capturing: the level meters still move.
  [ ] Player: pause, press "Start crop", move on, "End crop" -> playback and
      scrubbing stay inside the crop. Open a session, crop, press "+ Clip":
      a new clip appears in the same game folder.
  [ ] Player: "Audio tracks" opens instantly; fullscreen button (or F) works.
  [ ] Delete / overwrite prompts are game-capture dialogs, not Windows boxes.
  [ ] Edit a clip: crop, Audio tracks -> mute everything but the mic, lower
      it, Save as a copy. Open the copy: it plays the (mic-only) combined
      mix by default; Audio tracks shows each track by name (the game's
      name, Microphone, Discord, Spotify...).
  [ ] Gallery: tick the circle on a few cards (after the first, clicking a
      card ticks it too), press the red Delete button -> one confirmation,
      all removed. Ctrl+A selects all, Esc clears.
  [ ] Settings > Audio > Add application track: a list of running apps
      appears (apps playing sound first). Pick one -> name and executable are
      filled in. Open your YouTube Music installed web app first: it shows
      under "Installed web apps" with its own name and icon. Record a clip
      with it playing -> its track carries the music.
  [ ] Settings > Audio while capturing: level meters move; volume/mute act live.
  [ ] Right-click a clip: Open file location / Copy to clipboard (paste in
      Explorer or Discord) / Details / Delete.
  [ ] Close the window -> app stays in the tray; tray menu Pause/Quit work.
  [ ] Settings > General: change the library folder -> the gallery shows only
      that folder. "Additional folders" > Add folder (e.g. D:\Medal) -> its
      clips appear; remove it -> they disappear (files are left alone).
  [ ] Delete the library database and restart -> gallery rebuilds from files:
      %LOCALAPPDATA%\com.warionator.game-capture\library.sqlite

IF SOMETHING FAILS
  Log file: %LOCALAPPDATA%\com.warionator.game-capture\logs\game-capture.log
  (it includes the exact FFmpeg command line and FFmpeg's error output).
  Settings: %APPDATA%\com.warionator.game-capture\settings.json

KNOWN LIMITS
  - Games running as administrator need game-capture run as administrator
    for hotkeys to work.
  - Per-app audio needs Windows 10 2004 (build 19041) or newer.
  - Built with the GNU toolchain for this test; the CI/installer build uses MSVC.

FFmpeg 8.1 (GPL build from github.com/BtbN/FFmpeg-Builds) is included under
its own licence - see binaries\FFMPEG-LICENSE.txt.
