**game-capture 1.1.2**: lightweight game clipping and recording for Windows 10/11.

## What's new in 1.1.2
- **Smooth capture by default.** Capture now records the monitor the game is on instead of the game window. On Windows 10, window capture draws a yellow border around the game and makes clips judder. Your setting moves over once; you can still pick **Game window** under **Settings → Video**.
- **Other windows stay out of clips:**
  - **Alt+Tab** (and Alt+Esc, Ctrl+Esc, the Windows key) brings up the "Game not in focus" screen as you press the keys, before Windows switches, so neither the other window nor the Alt+Tab list shows up.
  - **While a game starts,** the focus screen stays up until the game is actually on screen. Games like Call of Duty showed the Steam library behind their window while loading or going fullscreen.
  - Other ways of leaving the game, such as clicking another window or the game closing, are caught within a few frames.
- **No more choppy video** when the "Game not in focus" screen is on: the capture keeps a steady 60 fps.
- **Follows the game's real window.** Games that open a launcher or splash window first (Call of Duty's "Game HQ"), or move their window after launch, are captured at the right size and position; a running recording continues in a new file.
- **Recording keeps going when the game window pauses** (minimised, loading, compiling shaders) instead of stopping with an error. Audio keeps recording.
- **Fixed the "Game not in focus" screen with FFmpeg 8.** It could silently fail, so alt-tabbed apps were recorded.
- **Stopping a long session recording saves in seconds:** the MP4 is written while you record.
- If you have 1.1.0 or 1.1.1 installed, it offers this version automatically with **Restart to update**.

For everything new in 1.1 (automatic updates), see the [1.1.0 release notes](https://github.com/Warionator/game-capture/releases/tag/v1.1.0).

## Download & run
Pick one:
- **Installer:** run `game-capture_1.1.2_x64-setup.exe`. It installs for your user only (no admin needed) and adds a Start menu entry.
- **Portable:** download `game-capture-1.1.2-windows-x64.zip`, extract the whole folder somewhere permanent and run `game-capture.exe`. Keep the `binaries` folder next to the exe. `TESTING.txt` in the folder has a checklist.

Neither has a Windows code-signing certificate, so SmartScreen may warn: choose **More info → Run anyway**.

On first launch it disables Windows Game Mode and registers itself to start with Windows (both on by default; turn them off under Settings → System).

## Highlights
- **Replay buffer:** last 15 s – 20 min in RAM, or on disk when it doesn't fit. Saving is a lossless stream copy.
- **Session recording:** manual, or automatically for each game session. Clips and recordings have independent quality settings.
- **GPU capture:** records the monitor the game is on (or just the game window, if you choose) and encodes on the GPU with NVENC, AMF or QuickSync; zero-copy where supported, with automatic fallback. No hooks or injection.
- **"Game not in focus" screen:** shown while you're tabbed out or the game isn't on screen yet, so other apps never appear in clips.
- **Multi-track audio:** Master mix, Game (named after the game), Microphone (noise suppression plus a live noise gate), Discord, and any app you pick from a list of running apps, including installed web apps.
- **In-game popups with chimes:** capture ready, "Saved last 2:00", recording started/stopped… The popup never takes focus and is excluded from capture.
- **Library:** `<library>/<Game>/<date>_<Clip|Session|Screenshot>.<ext>`, with metadata embedded in each file and a self-healing index. Filters, multi-select delete, and extra folders (e.g. Medal) on request.
- **Player and editor:** combined or per-track audio, crop with handles or Start/End crop, save over the original or as a copy, "+ Clip" from long sessions, fullscreen.
- **Desktop capture is off by default:** nothing is captured outside games unless you enable it.

## Known limitations
- Exclusive-fullscreen games draw over every window, so popups only show in borderless/windowed mode.
- Games running as administrator need game-capture run as administrator for hotkeys, and for the early Alt+Tab switch, to work.
- Installed web apps share their browser's audio process, so a web-app track also records other tabs in that browser.
- Per-app audio needs Windows 10 2004 (build 19041) or newer.
